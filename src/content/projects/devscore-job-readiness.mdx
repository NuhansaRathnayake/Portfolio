## Overview

DevScore's idea is "Hire on proof, not promises." A resume lists skills, but a list is not evidence. DevScore compares the skills a candidate claims with verifiable evidence mined from their GitHub activity and other sources, then turns the result into a Job Readiness Score for recruiters.

## What it does

- Compares resume-claimed skills with evidence taken from GitHub.
- Gives students, recruiters and admins their own access and dashboards.
- Signs users in with Google or GitHub and links a GitHub account for evidence mining.
- Parses an uploaded resume with a separate CV parser service that extracts the skills it mentions.

The figures on the project image are illustrative, to show how the dashboard looks.

## My contribution

My main focus was documentation and managing it. I kept the project's documents organised and up to date, and helped the team track what was planned, in progress and finished, so the written record matched the work being built.

## Tech stack

A React (Vite) front end, a Node.js and Express back end, Supabase (Postgres) for data, and a Python microservice for resume parsing.
