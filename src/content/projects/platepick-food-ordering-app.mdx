## Overview

PlatePick is a simple, user-friendly Android app for ordering food. A customer signs in, browses the menu by category, adds meals to a cart and checks out. The project focuses on the core ordering journey and has no real-time payment gateway: it supports Cash on Delivery and a manual card selection.

## What it does

- Secure login and registration, with email and strong password validation.
- A menu grouped into categories such as burgers, pizzas and drinks.
- A cart page that collects the chosen meals before checkout.
- Checkout with delivery address and phone number validation.
- Order history, with placed orders saved in a local database.

## My contribution

I worked on the app as part of a team of three and helped develop its ordering features. I also used GitHub to manage and update the project tasks, so the team could see what was done and what was still open.

## Tech stack

Java, with XML layouts using Material Design components, SQLite for user details and order history, and Android Studio as the development environment.

## What I learned

- Splitting an app into small tasks makes teamwork easier, because each person knows what they own.
- Keeping task status on GitHub gave the team one place to check progress.
- Working through problems together improved both my problem-solving and my communication.
