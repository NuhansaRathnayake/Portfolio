## Overview

Tours Beyond i is a website developed for a tour operating company. It presents Sri Lankan destinations under the line "Discover Sri Lanka, beyond the ordinary," and helps visitors choose a destination or a package and get in touch.

## What it includes

- A page for each destination, including Sigiriya, Ella, Kandy, Yala, Galle, Anuradhapura, Polonnaruwa, Dambulla, Nuwara Eliya, Minneriya, Trincomalee and Yapahuwa.
- Four tour package pages.
- A photo gallery, an about page and a testimonials page.
- A contact form that sends the visitor's enquiry by email.

## My contribution

I started this project on my own and built it end to end, from the page layout and styling to the PHP pages and the contact form.

## Tech stack

PHP, HTML, CSS and JavaScript, with Bootstrap for layout and PHPMailer for sending the contact form.

## What I learned

- Planning the pages and content first made the build faster and kept the site consistent.
- Owning a project from start to finish showed me how much of delivery is organising the work, not only writing code.
