## Overview

Tours Beyond i is a web application for tourism and travel management. It presents Sri Lankan destinations, including Sigiriya, Ella, Kandy, Yala and Galle, under the line "Discover Sri Lanka, beyond the ordinary."

## My contribution

I contributed to the platform as a team member. I helped organise the project tasks and developed web features, which gave me experience in collaborating with others and coordinating a project as well as building one.

## Tech stack

HTML, CSS and JavaScript for the front end, Bootstrap for layout and MySQL for the data.

## What I learned

- A shared task list keeps a team aligned when several people work on one codebase.
- Coordinating the work was as valuable as the code itself, and it is the part of the project that points me toward project management.
